Zephyr 0.1.2

  • Signed in-app updates from GitHub Releases: Zephyr → Check for Updates…, daily checks, optional install on quit.
  • Reading area stays centered between the sidebar and the outline; wide tables, images and diagrams stay in the column.
  • Sidebar: resizable, files listed under Home, an icon-only mode with a files panel.
  • Quick input: paired $ and *, $$ and fenced code blocks on Return, image insertion after !, closing HTML tags.
  • Underline (⌘U) and highlight (⇧⌘H); > shows a quote immediately.
  • Mermaid: smooth curves, loop-back edges outside the main flow, labels that sit on their own line.
  • Themes are editable JSON files; new interface-font setting.
  • Tables: drag column dividers, add rows and columns from bars that appear on hover.
